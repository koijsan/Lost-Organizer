# Lost Ark – Raid Organizer

Organizador de PTs e Raids de Lost Ark. Monte grupos de 4 e 8 jogadores com drag & drop, veja sinergias, filtre por iLvl e controle o reset semanal.

Tudo roda no navegador (sem servidor, sem cadastro). Os dados ficam no `localStorage`; use **Exportar / Importar** para backup.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub (ex.: `lostark-raid-organizer`).
2. Envie `index.html` e este `README.md` para a branch `main`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)` e clique em **Save**.
5. Em ~1 minuto o site estará em `https://SEU-USUARIO.github.io/lostark-raid-organizer/`.

Para atualizar, basta substituir o `index.html` no repositório.
