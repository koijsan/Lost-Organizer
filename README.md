# Lost Ark – Raid Organizer

Organizador de PTs e Raids de Lost Ark. Monte grupos de 4 e 8 jogadores com drag & drop, veja sinergias, filtre por iLvl e controle o reset semanal.

Tudo roda no navegador (sem servidor, sem cadastro). Os dados ficam no `localStorage`; use **Exportar / Importar** para backup.
